# 📦 Apps

Repositório de aplicativos prontos pra instalar, com instruções de uso.
Cada pasta é um app — entre nela, baixe o instalador e siga o README.

## Apps disponíveis

| App | Plataforma | O que faz |
|---|---|---|
| [Wispr Local](Wispr%20Local%20for%20Mac/) | macOS 14+ | Ditado por voz em qualquer app: fale, a IA ajusta o texto e ele entra direto no campo onde você está digitando. 100% local, com atalho de teclado. |
| [Mac Spy](Mac%20Spy%20for%20Mac/) | macOS 13+ · Apple Silicon | Monitor leve de CPU, memória e processos na barra superior, com busca, gráficos e encerramento manual. |
| [Loom Local](Loom%20Local%20for%20Mac/) | macOS 15+ | Gravador de tela com a sua câmera numa bolinha: ao parar, o link já está pronto — com transcrição, resumo, título e capítulos feitos por IA. |
